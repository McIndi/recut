# Recut Project

This directory contains the source code for the Recut (REimagined Core Utils for Teaching) project.

## Directory Structure

```
recut/
├── src/
│   └── recut/
│       ├── __init__.py
│       └── commands/
│           └── __init__.py
├── tests/
│   ├── __init__.py
│   └── test_*.py
├── README.md
├── pyproject.toml
├── .gitignore
├── .editorconfig
├── .flake8
└── .bandit
```

- **src/recut/**: Main package directory containing all command implementations
- **tests/**: Test directory containing pytest test files
- **pyproject.toml**: Project metadata and tool configuration
- **.editorconfig**: Editor configuration for consistent code formatting
- **.flake8**: Flake8 linter configuration
- **.bandit**: Bandit security scanner configuration
